# The Moon Finally Answers Back

make.fun bounty entry. One line, in the voice of the Moon replying at last to the wishes, howls and late-night promises of everyone staring up at it.

> You howl at me once a month and call it a relationship. I have been here four billion years. You are a phase.

Run with Node 22: `node main.ts`. It writes the line to `(MAKEFUN_OUTPUT_DIR ?? "/output")/entry.txt`.
